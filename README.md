# CookieKit

## What is CookieKit?

CookieKit is a Safari extension for iPhone and iPad that lets you view, edit,
import, and export cookies for the current website. Everything is processed
locally on your device.

## Features

- View and edit Safari cookies
- Import and export Netscape `cookies.txt` and JSON files
- No accounts, analytics, tracking, or external servers
