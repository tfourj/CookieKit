Safari extension for iPhone and iPad

Export the current page’s cookies

CookieKit creates a Netscape cookies.txt file you can share or copy without sending cookie data to a developer server.

Check Safari Settings

Get started

Enable CookieKit in Safari

  1. 1

    Open Safari extension settings

    In Settings, choose Apps, Safari, then Extensions. On some versions you can search Settings for Safari.

  2. 2

    Turn on CookieKit

    Select CookieKit, enable the extension, and allow access for the websites where you intend to export cookies.

  3. 3

    Export from the current page

    Open an http or https page in Safari, tap the page menu, choose CookieKit, then Share file or Copy contents.

The direct Settings button appears on supported iOS and iPadOS versions. The manual steps above work on iOS and iPadOS 18 or later.

Local by design

Cookies exist in popup memory only. CookieKit has no analytics, accounts, third-party SDKs, or network service.

Compatible format

Exports the seven-field Netscape format used by tools such as curl. SameSite and partition metadata cannot be preserved.

Treat exports like passwords. Cookies can grant access to signed-in accounts. Share an export only with a destination you trust, then delete it when it is no longer needed.
