Get started

Enable CookieKit in Safari

  1. 1

    Open Safari extension settings

    In Settings, choose Apps, Safari, then Extensions. On some versions you can search Settings for Safari.

  2. 2

    Turn on CookieKit

    Select CookieKit, enable the extension, and allow access for the websites whose data you want to manage.

  3. 3

    Manage the current page

    Open an http or https page in Safari, tap the page menu, choose CookieKit, then use the Cookies or Local Storage tab to view, edit, import, or export the website's data.

If Settings opens at the main screen, choose Apps, Safari, then Extensions. Website access is managed per site by Safari.

Local by design

Website data is read into popup memory only. CookieKit has no analytics, accounts, third-party SDKs, or network service.

Compatible formats

Export the seven-field Netscape format used by tools such as curl, or JSON that preserves the metadata Safari provides. Local Storage entries can also be imported and exported as JSON.

Treat exports like passwords. Cookies can grant access to signed-in accounts. Share an export only with a destination you trust, then delete it when it is no longer needed.
